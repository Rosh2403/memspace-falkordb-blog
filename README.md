# Memspace — FalkorDB Engineering Blog

A standalone static website describing Memspace's FalkorDB memory architecture.

## Website
https://memspace-falkordb-blog.vercel.app

## Local preview
Open `index.html` in any web browser. No build step is required.

## Deployment
This site is currently deployed to Vercel as the `memspace-falkordb-blog` project.
The existing Vercel deployment was uploaded directly; it is not yet linked to this GitHub repository.

## Updating
Edit `index.html`, commit changes, and deploy again. Once the GitHub repository is connected in Vercel, pushes can trigger deployments.
